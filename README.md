# Product Price Tracker

A web application that monitors product prices from an online store and tracks historical trends.

## Tech Stack
- **Backend:** Node.js, Express, Playwright
- **Frontend:** React, Vite, Recharts
- **Database:** Supabase (PostgreSQL)

## Getting Started

### 1. Backend
```bash
cd backend
npm install
npx playwright install chromium
npm run dev
```

### 2. Frontend
```bash
cd frontend
npm install
npm run dev
```
